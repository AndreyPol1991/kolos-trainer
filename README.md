# Колос — тренажёр профессии системного аналитика

Интерактивный тренажёр для тех, кто входит в профессию системного аналитика. Сквозной кейс — сеть пекарен «Колос» и ИТ-подрядчик «Квант Софт», где вы — младший аналитик.

**Открыть:** https://andreypol1991.github.io/kolos-trainer/

За 6 недель:

- **Неделя 1.** Из чего сделан софт, кто такой системный аналитик, команда разработки, жизненный цикл, каскад, V-модель, итерации, Agile.
- **Неделя 2.** Что такое требование: потребность и решение, уровни и виды, качество формулировок, жизнь требования.
- **Неделя 3.** Работа с бизнесом: заинтересованные лица, искусство вопроса, интервью, наблюдение, техники выявления, встречи и договорённости.
- **Неделя 4.** User story, use case, нефункциональные требования, процессы, ценность и приоритеты, документы.
- **Неделя 5.** Аналитик в команде: Scrum, Kanban, разработчики и дизайнер, QA и приёмка, изменения и конфликты.
- **Неделя 6.** От требований к системе, защита проекта, словарь аналитика, подготовка к собеседованию.

Каждая тренировка: «1. Теория» — живые разделы «Как это работает», «2. Практика» — задания с проверкой и разбором.

Прогресс хранится в браузере. Отчёт для преподавателя — кнопка «Отчёт» вверху страницы.
